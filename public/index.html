How value is calculated

We collect odds from multiple bookmakers for every soccer match tomorrow. For each match, we compute the consensus implied probability by averaging the implied probabilities (1 / decimal odds) across all bookmakers, then remove the overround (vig) to derive fair probabilities. A bet has positive value when a bookmaker offers odds that are higher than what the fair probability suggests — meaning you're getting better-than-fair compensation for the risk. The value % tells you how much edge you'd have: +5% means for every $100 wagered, you'd expect $5 profit if the fair probabilities are accurate.
